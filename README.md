# Road 55 Gaming Center: موقع حجز الغرف

موقع حجز غرف PS5 (عربي RTL، للموبايل أولاً). صفحة وحدة: Hero، بعدين الحجز بثلاث مراحل، والأسعار، وكيف نحجز. لوحة الإدارة على `/#admin`.

```
public/            الموقع (static، بدون build)
  core.js          كل المنطق: الأسعار، الslots، التعارض، التحقق. نفس الملف للمتصفح والسيرفر والـ tests
  app.js           واجهة الزبون
  admin.js         لوحة الإدارة (بتنحمل بس على /#admin)
  silk.js          خلفية الـ hero (خطوط حرير متحركة بالكود)
  assets/logo.svg  لوغو مؤقت
netlify/functions/api.mjs   الـ function الوحيدة: /api (تخزين + HTTP بس)
test/core.test.mjs          الـ tests
```

## التشغيل محلياً
```bash
npm install
echo ADMIN_PIN=اختار-رمز-طويل > .env
npm test          # 17 test
npm run dev       # http://localhost:8888   والأدمن: http://localhost:8888/#admin
```

## النشر على Netlify
1. ارفع المشروع على GitHub واربطه بـ Netlify (Add new site > Import). أو من الجهاز: `npx netlify deploy --prod` بعد `npx netlify login` و `npx netlify init`.
2. الإعدادات موجودة بـ `netlify.toml` (publish = `public`، functions = `netlify/functions`). ما في build command.
3. **Site settings > Environment variables**: ضيف `ADMIN_PIN`. استخدم رمز طويل (8 أرقام أو أكثر)، لأنه ما في حد لعدد المحاولات.
4. Netlify Blobs بيشتغل لحاله، ما بدها إعداد.

## كيف تبدل اللوغو والأرقام
- **اللوغو**: `public/assets/logo.svg` (مرسوم من اللوغو الأصلي). لتبديله حط ملفك بنفس الاسم. إذا PNG: حطه بـ `assets/` وغير `logo.svg` بـ `index.html` و `admin.js`.
- **فيديو للـ hero**: حط `public/assets/hero.mp4` وبيطلع تلقائياً بدل الخطوط المتحركة (muted, loop, playsinline، مع طبقة غامقة).
- **رقم الواتساب، الأسعار، عدد الغرف، الدوام، مدة الحجز المعلق**: كلها بأول `public/core.js` (`WHATSAPP_INTL`، `ROOM_TYPES`، `OPEN_MIN`، `CLOSE_OPTIONS`، `PENDING_MS`...). رقم الفوتر بـ `index.html`.
- **الخطوط**: Handjet (خط gaming بكسل) للعناوين والأرقام والأوقات، و Tajawal للنص العادي والمبالغ. بتتغير من `--display` و `--font` بأول `styles.css`.

## قرارات أخذتها
- **الslot بيضل متاح لحد 30 دقيقة بعد بدايته** (مثلاً 8:00 م بينحجز لحد 8:30). بعدها "خلص". الحجز اليدوي من الأدمن ما عليه هالقيد (للي داخل المحل هلأ).
- **اليوم بيتغير الساعة 6 الصبح**: أي وقت قبل 6 ص بيتبع ليلة امبارح.
- **الأيام المعروضة**: يوم الدوام الحالي + 13 يوم. إذا الساعة 1 بالليل، "اليوم" يعني الليلة الحالية.
- **اختيار سريع (طلبك: حجز أسهل)**: فوق جدول الساعات في أزرار "كم ساعة بدك؟" (1 لـ 6، الافتراضي 2، والـ 3 و 6 مكتوب عليها كم ساعة مجانية). أول كبسة على وقت بتختار الساعات كلها مرة وحدة. الكبسات اللي بعدها بتمد أو بتقصر الاختيار حسب القاعدة الأصلية (تعبئة المدى إذا كله فاضي، وإلا اختيار جديد). في زر "امسح".
- **الزبون اللي حجز قبل**: اسمه ورقمه بينحفظوا على جهازه (localStorage) وبيتعبوا لحالهم المرة الجاية.
- **رقم الحجز**: `R55-` + 4 أرقام، فريد داخل اليوم. الأدمن بيشتغل على (التاريخ + الرقم).
- **الأدمن بيقدر يأكد حجز معلق انتهى** إذا الوقت لسا فاضي. **وما بيقدر يقصر وقت الإغلاق** إذا في حجز نشط بعد الوقت الجديد.
- **حد 3 حجوزات معلقة** بيتحسب لنفس الرقم بنفس يوم الدوام، والرقم بيتوحد (`+962 7…` و `9627…` و `7…` كلها بتصير `07…`). الأرقام العربية (٠٧٩…) مقبولة.
- **فتح واتساب**: الموقع بيفتح تاب فاضي لحظة الكبسة (عشان المتصفح ما يمنعه) وبيوجهه على wa.me بعد ما السيرفر يرد. إذا انمنع، في زر "ابعت على واتساب" بشاشة النجاح. آخر حجز بينحفظ بالـ sessionStorage عشان شاشة النجاح تضل لو رجع للصفحة.
- **الوقت**: كل الحسابات بتوقيت Asia/Amman عن طريق `Intl`، والمتصفح بيصحح ساعته من وقت السيرفر (لو ساعة الجهاز غلط).
- **التخزين**: blob لكل يوم `day-YYYY-MM-DD` = `{close, bookings[]}` بـ store اسمه `road55`. الحجوزات المعلقة المنتهية ما بتنحذف (الأدمن بيشوفها "انتهى")، بس ما بتحجز الوقت.
- **Race condition**: كل كتابة بتقرأ الـ etag وبتكتب بـ `onlyIfMatch` (أو `onlyIfNew` لأول حجز باليوم)، وإذا تغير الملف بنعيد المحاولة لحد 6 مرات وبعدين 503. **ملاحظة**: سيرفر Blobs المحلي (`netlify dev`) ما بيرجع etag، فمحلياً بس الكتابة بتصير عادية بدون حماية (لما `NETLIFY_DEV=true`). على Netlify الحقيقي الحماية شغالة، وإذا ما رجع etag لأي سبب السيرفر بيرفض (503) بدل ما يكتب فوق حجز حدا.
- **خلفية الـ hero**: canvas 2D بدقة نص الشاشة (التكبير الناعم بيعطي شكل الحرير وبيخففها). بتقلل عدد الخطوط والدقة لحالها إذا الجهاز بطيء، بتوقف لما تطلع برا الشاشة أو التاب مخفي، وصورة ثابتة مع `prefers-reduced-motion`. بتبلش بعد أول رسم للصفحة عشان ما تأخر العنوان.
- **اللوغو**: مرسوم SVG من صورتك (`assets/logo-original.png`): "55" بخطوط نيون وردية متوازية و "شارع" بالسيان بخط Amiri. الخط مدمج جوا الـ SVG (بس حروف "شارع"، حوالي 3KB) عشان يطلع نفس الشكل على كل الأجهزة. الصورة الأصلية مستخدمة كصورة المشاركة (og:image).
- **إنستغرام**: الصفحة طلبت تسجيل دخول وما قدرت أشوف البوستات، فالألوان والستايل مبنية على الوصف اللي بعثته.
